# Contributing

This hub repo serves `guides.brandon-behring.dev` landing + `/methodology` + `/about`. Per-guide content lives in sibling repos.

## Where to send PRs

| Change | Repo |
|---|---|
| Hub landing, `/methodology`, `/about`, style guide v0.0 | This repo (`guides`) |
| Pilot guide chapters or companion | `guides-experimentation` |
| Future guides (e.g., `prompt-injection`) | Future per-guide repos |
| Scaffold / shared components | [`book-scaffold-astro`](https://github.com/brandon-behring/book-scaffold-astro) |

## Issues

- Methodology / hub feedback: file in this repo
- Per-guide factual corrections: file in the per-guide repo
- Scaffold bugs: file in `book-scaffold-astro` with label `consumer:guides`

## AI disclosure

This repo is co-authored with Claude (Anthropic) via Claude Code. PRs that touch content should preserve the AI co-authorship disclosure (`<AICollaborationDisclosure>` component on relevant pages). See `/methodology` for the full workflow.
