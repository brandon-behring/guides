# AI-Writing Evaluation, Detection & Watermarking

This file covers the evaluation question: can blind raters distinguish AI-assisted from human-only writing, and what tooling exists to detect or watermark machine-generated text? Empirical productivity / quality studies live in `01_llm_writing_efficacy.md`; disclosure norms live in `02_disclosure_norms.md`.

---

## F2. Detection & Watermarking Methods

| Title | Authors (year) | Venue | arXiv/DOI | GitHub | One-line description | Key contribution |
|-------|----------------|-------|-----------|--------|----------------------|------------------|
| DetectGPT: Zero-Shot Machine-Generated Text Detection using Probability Curvature | Mitchell et al. (2023) | ICML 2023 | arXiv:2301.11305 | — | Zero-shot detector using the observation that model-generated text sits near local maxima of the source model's log-probability function | Canonical zero-shot detection reference using probability curvature; widely cited baseline for follow-on detection work |
| A Watermark for Large Language Models | Kirchenbauer et al. (2023) | ICML 2023 | arXiv:2301.10226 | — | Embeds a statistical watermark at generation time by biasing the sampling distribution toward a pseudorandom "green list" of tokens | Foundational LLM-watermarking paper introducing the green-list / red-list sampling approach that became the reference method |
