# Documentation Methodology — Hypertext and Cross-Link Patterns

Theory and practice for cross-link discipline in reference works: evergreen notes (Matuschak), the Memex essay (Bush 1945), Zettelkasten (Luhmann tradition), Smart Notes (Ahrens), and Wikipedia's editorial linking conventions. Relevant to the `<XRef>` cross-guide-link convention for the public-guides repo.
