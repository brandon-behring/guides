# Documentation Methodology — Hypertext and Cross-Link Patterns

Theory and practice for cross-link discipline in reference works: evergreen notes (Matuschak), the Memex essay (Bush 1945), Zettelkasten (Luhmann tradition), Smart Notes (Ahrens), and Wikipedia's editorial linking conventions. Informs the `<XRef>` cross-guide-link convention for the public-guides repo.

## E1. Modern hypertext essays

- **Evergreen notes** — Matuschak (notes.andymatuschak.org, ongoing).
  - **Source:** https://notes.andymatuschak.org/Evergreen_notes
  - **Status:** Unverified (website / ongoing).
  - **Mechanism:** Essays defining evergreen notes — concept-oriented, atomic, densely linked notes meant to be refined over time and to compound in value through link density; surfaced via a public garden-style site (backlinks shown inline).
  - **Integration:** Modern reference for densely-linked concept-oriented note systems; directly informs cross-guide reference discipline in the public-guides repo (every guide is treated as a "note cluster" with associative links to related guides).

- **As We May Think** — Bush (The Atlantic Monthly, 1945).
  - **Source:** https://www.theatlantic.com/magazine/archive/1945/07/as-we-may-think/303881/
  - **Code:** —
  - **Mechanism:** Essay proposing the Memex — a desk-sized mechanical hypertext device for associatively linking documents — as a model for organizing scholarly knowledge; predates the web by nearly five decades.
  - **Result:** Foundational pre-web hypertext essay; cited as origin of associative-linking traditions and routinely invoked in modern note-system and PIM literature.
  - **Status:** Unverified (no widely-known repo).

## E2. Zettelkasten tradition

- **Introduction to the Zettelkasten Method** — Schmidt / Zettelkasten.de (zettelkasten.de, ongoing; based on Luhmann archive).
  - **Source:** https://zettelkasten.de/introduction/
  - **Status:** Unverified (website / ongoing).
  - **Mechanism:** Introduction to the Zettelkasten method developed by sociologist Niklas Luhmann — atomic notes with unique IDs cross-linked by association rather than hierarchical filing; method involves capturing literature notes, transforming them into permanent notes, and connecting via link structure.
  - **Integration:** Practitioner-oriented primary source for the Luhmann-tradition Zettelkasten method; the "unique ID + atomic note + associative link" pattern maps directly onto the public-guides repo's stable-anchor cross-reference convention.

- **How to Take Smart Notes: One Simple Technique to Boost Writing, Learning and Thinking** — Ahrens (CreateSpace, self-published, 2017).
  - **Source:** https://www.soenkeahrens.de/en/takesmartnotes
  - **Code:** —
  - **Mechanism:** Book popularizing Luhmann's Zettelkasten method for English-speaking knowledge workers; offers workflow guidance covering literature notes (capture), permanent notes (refinement), and project notes (writing).
  - **Result:** Widely-cited English-language popularization of the Zettelkasten method for non-academic knowledge work; surfaces the method to readers outside German sociology.
  - **Status:** Unverified (no widely-known repo).

## E3. Encyclopedic linking conventions

- **Wikipedia:Manual of Style/Linking** — Wikipedia editorial community (en.wikipedia.org, ongoing).
  - **Source:** https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style/Linking
  - **Status:** Unverified (website / ongoing).
  - **Mechanism:** Wikipedia community guideline on internal linking — covering when to link (relevant topics), the "link on first mention" convention, disambiguation when terms are ambiguous, and link density (avoid over-linking).
  - **Integration:** Operational community guideline tested at encyclopedia scale; the "first mention only" convention is a useful default for the public-guides repo's `<XRef>` placement discipline.
