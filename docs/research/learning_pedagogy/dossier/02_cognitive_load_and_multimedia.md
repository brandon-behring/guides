# Cognitive Load and Multimedia Learning

This file covers Sweller's cognitive-load theory (intrinsic / extraneous / germane load, expertise reversal) and Mayer's cognitive theory of multimedia learning (CTML). These two lines together govern instructional design for technical material.

## B1. Cognitive Load Theory

| Title | Authors (year) | Venue | arXiv/DOI | GitHub | One-line description | Key contribution |
|-------|----------------|-------|-----------|--------|----------------------|------------------|
| Cognitive Load During Problem Solving: Effects on Learning | Sweller (1988) | Cognitive Science 12(2) | https://doi.org/10.1207/s15516709cog1202_4 | — | Foundational paper introducing cognitive-load theory and arguing that conventional problem-solving practice imposes high extraneous load that interferes with schema acquisition. | Establishes cognitive-load theory as the framework for instructional design; introduces the distinction between solving problems and learning from them. |
| Expertise Reversal Effect and Its Implications for Learner-Tailored Instruction | Kalyuga (2007; based on Kalyuga, Ayres, Chandler & Sweller 2003) | Educational Psychology Review | https://doi.org/10.1007/s10648-007-9054-3 | — | Review article on the expertise reversal effect: instructional supports that help novices can hinder experts. | Documents that worked examples and other novice-friendly scaffolds reverse polarity at higher expertise levels, requiring adaptive instructional design. |
